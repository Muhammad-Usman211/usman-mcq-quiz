# Usman MCQ Academy

## Run locally
```bash
pip install -r requirements.txt
streamlit run main.py
```

## Deploy
1. Upload `main.py`, `requirements.txt`, and `questions.json` to GitHub.
2. Open https://share.streamlit.io
3. Create app and select `main.py`.

## Admin password
The demo password is `admin123`. For public use, configure `QUIZ_ADMIN_PASSWORD` using Streamlit secrets.
